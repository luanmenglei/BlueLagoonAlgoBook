先用正确的算法和普通实现跑满规模数据，再定位耗时热点。以下工具改变常数、内存分配或指令选择，不保证在每个编译器和 CPU 上更快。对拍验证正确性，基准测试比较速度；二者不能互相替代。

取模怎么选：编译期常量模数先直接用 `%`；编译器可能自行转成乘法和移位。运行时给定且大量复用的 32 位模数可用 Barrett32，接受奇数和偶数，也支持模数 1。Barrett32::reduce 的被除数是 u64，不能把两个 u64 的乘积截断后传入；完整 64 位模乘仍用 Modular.h 的 u128 版本。一次模乘就重建 Barrett 对象，会把预处理除法带回热点。

Montgomery32 仅用于 32 位奇模数。普通数 x 转成 xR mod m，R=2^32；先 encode，一串乘加都在域内做，最终 decode。mul 只接受同一模数的域内数；直接乘两个普通整数会算出错误结果。加减也必须保留域内表示；不要每次乘法都来回转换。对象内的 m、neg、r2 不可修改。

FastDiv.h 对应参考笔记的 64 除 32 位 divl 技巧，返回 32 位商与余数。y 必须非零，且 x 的高 32 位小于 y；这等价于商小于 2^32。它仍使用硬件除法，与倒数取模不同；不满足范围时使用普通 /、% 或 Barrett。GNU x86 以外走可移植回退；定义 BL_PORTABLE 可强制关闭本章的汇编和 AVX2 分支。

位运算统一使用无符号数，避免有符号溢出。lsb_index/msb_index 对零返回 -1；底层 ctz/clz 不能直接传零。popcountll 统计 1 的个数。枚举非零子集用 `for(u64 s=m; s; s=(s-1)&m)`，零子集另算。next_mask 枚举相同 popcount 的掩码；限制在 n 位时，n<64 可检查结果小于 `1ULL<<n`，n=64 则以 nullopt 结束，不能写 `1ULL<<64`。k=0 的空集合单独处理，k=64 的初值为 `~0ULL`。

FastIO.h 已在常用补充章：fread/fwrite 缓冲读写整数，支持 EOF 和 i128。对象各含 64 KiB 缓冲，深递归中不要反复创建。批处理 IO 不与 cin/scanf 混用；交互输出要显式 flush。只是输入量小时，关闭同步的 iostream 往往已足够，先测再换。

哈希：先考虑 unordered_map 的 reserve 和 max_load_factor，减少扩容；RandomHash.h 的 SplitMix64 用于混洗整数键。FlatHash 使用连续数组线性探测，预估 expected 为键数而不是桶数。支持全部 u64 键，负整数可显式转 u64。无单项删除；扩容使旧指针引用失效，所以不要在保存一个元素引用后再插入可能触发扩容的新键。clear 保留容量和旧值占用的资源，适合轻量值；有单项删除或稳定引用要求时另选容器。

内存池：Arena 用于主席树、动态线段树等大量小结点；一次给足容量，make 按类型对齐并调用构造。reset 只回收整块空间，不调用析构，所以禁止 string/vector 等非平凡析构类型。旧指针在 reset 后全部失效。超容量抛异常，不能悄悄写出界；特殊的超对齐 SIMD 对象不在支持范围。结点下标加 vector 也是紧凑表示，但 vector 扩容同样会使指针失效。

SIMD 与展开：Simd.h 用数组异或演示 4 路展开、AVX2 非对齐加载和尾部处理。公开入口 xor_words 自动检测 AVX2 支持，不支持则回退；测试同时比较两条路径。AVX2 函数局部使用 target 属性，不对整份程序开 avx2 或 march=native。输入区间允许完全相同，不允许部分重叠。手动展开会增大代码体积，内存带宽受限时 SIMD 也未必提升；更换运算必须重新处理依赖、溢出、对齐和尾部。

编译选项：基准先固定 `-std=c++20 -O2`。再比较 O3、局部展开或向量化，不把 Ofast/fast-math 当作默认开关；它们可能改变浮点语义，几何判断尤其要重新验证。CPU 专用指令仅在目标环境明确支持或具有运行时分派时使用。函数属性和 CPU 检测的官方文档链接见仓库 SOURCES.md。

栈空间：teamnote 的手写 rsp 换栈依赖 ABI、栈对齐、编译器和平台，不作为本库可直接粘贴的模板。深 DFS 优先改显式栈，大数组移到堆或全局；Linux 本地可在允许的硬限制内用 `ulimit -s` 调整栈，Windows MinGW 的链接选项示例为 `-Wl,--stack,268435456`，仅作用于自己链接的程序。评测机若不接受这些设置，不应依赖它们；扩大栈也要计入内存预算。

计时：用 steady_clock，预先生成输入，把随机数、读写和初始化移出被测区间；构造成本另测。累加并输出校验值以防循环被消去，使用相同输入交替运行基线和候选，多轮比较中位数。报告编译器、选项、CPU、数据规模、模数分布和是否包含预处理。正确性测试覆盖边界，性能测试覆盖真实热点；本章的回归测试不宣称加速倍率。
